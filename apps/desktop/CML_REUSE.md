# CML reuse ledger

Reference: https://github.com/csshlok/CML at commit `4183ad4` (MIT, "Copyright (c) 2026 Vault contributors").
The clone lives outside this repository (`Downloads/vthacks14-reference/CML`) and is not modified.
**No CML source code, assets, or branding has been copied.** Every row is concept-only, reimplemented independently. Reviewer: pending SD.

## Adopted

| CML source | Target here | Concept taken | Left behind |
| --- | --- | --- | --- |
| `src/styles.css` (tokens) | `src/styles/app.css` | Warm light palette, flat surfaces, hairline borders, no shadows, semantic token names mapped to shadcn, 5px scrollbars, body overflow hidden | Cluster/badge colours, onboarding art, brand names |
| `src/styles.css` (window chrome), `WindowChrome.tsx` | `WindowChrome.tsx`, `.window-chrome*` | Frameless window with a 6px reveal zone and auto-hiding 32px drag bar; min/max-restore/close; close hover red; sidebar as drag region | Their component code and class names |
| `electron/window-controls.cjs` | `electron/window-controls.cjs` | Controls resolve the sender's window; state pushed on one channel; safe no-ops | CML channel names |
| `electron/main.cjs` window options | `electron/main.cjs` | `frame:false`, `autoHideMenuBar`, `backgroundColor`, `contextIsolation`, `sandbox`, popup/navigation denial, fixed title, lifecycle logging | The 2,183-line monolith, Vault startup, tunnels |
| `electron/preload.cjs`, `ipc-errors.cjs` | `electron/preload.cjs`, `ipc-errors.cjs` | Frozen narrow bridge, sandboxed preload, clean IPC errors | Token exposure, dropped-file paths |
| `electron/runtime-descriptor.cjs` | `electron/runtime-descriptor.cjs` + reaper in `backend-runtime.cjs` | Identity-bound descriptor and stale-process checks for a child that outlived a crash | Their ports/identity, service names |
| `AppShell.tsx` layout | `components/AppShell.tsx` | 220px sidebar, search box with shortcut, primary nav, status footer, skip link, focus to main on navigation | Their nav items, tour, health panel |
| `CommandPalette.tsx` | `components/CommandPalette.tsx` | Ctrl/Cmd+K palette (cmdk) | Their commands |
| `product/Feedback.tsx`, `Layout.tsx` | `components/product.tsx` | Dot + text status label, skeleton, empty state, bordered section with header row | Their copy and lock/health states |
| `ui/*` (shadcn) | `components/ui/*` | Same shadcn/Radix primitives, flat variants | n/a (generated by the shadcn CLI, then restyled) |
| Isolated Electron profile for smoke runs | `CHANGE_ASSURANCE_USER_DATA_DIR` | Tests must not touch real data | Their packaging scripts |
| `electron/main.behavior.test.cjs`, `e2e/desktop-shell.spec.ts` | `electron/tests/main.behavior.test.cjs`, `e2e/resilience.spec.ts`, `e2e/fake-api.ts` | Test main.cjs against an Electron stub; mock the backend with `page.route`; assert geometry at the minimum window, large text and reduced motion | Their assertions, fixtures, and source-string "presentation" tests |
| Split-module lesson | `electron/*.cjs`, `src/services/*` | One purpose per module | 3,914-line `backend.ts` |

## Explicitly rejected

| CML pattern | Reason |
| --- | --- |
| TanStack Start / SSR / Cloudflare plugins | Local SPA |
| Vault navigation (11 destinations), chat, sources, map, tasks | Not part of Sentinel |
| Raw backend token exposed to the renderer | The main process owns the token |
| Variable-port packaged renderer HTTP server | Replaced by the stable `app://` protocol |
| Onboarding/first-use tour, startup HTML page | Not needed yet; the shell shows a "starting the local service" state instead |
